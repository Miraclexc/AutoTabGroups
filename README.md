# AutoTabGroups

用 AI 整理 Chrome 标签页，让打开的网页回到各自的主题。

AutoTabGroups 根据网页的标题、网址、描述和可选正文，将未分组标签加入 Chrome 原生标签组。你可以自己定义分类，也可以让 AI 提出分类方案，确认后再使用。

[下载安装包](../../releases) · [详细使用指南](docs/user-guide.md) · [开发与贡献](docs/development.md)

## 能做什么

- **按你的习惯分类**：只填分组名即可，也能补充描述、设置颜色，或让 AI 生成描述。
- **AI 提出分类方案**：根据打开的网页建议简短的分组名和描述，你可以编辑后采用。
- **逐次整理新增标签**：点击“更新分组”，只处理未分组网页，保留已经整理好的标签。
- **选择读取范围**：整理当前窗口或所有普通窗口；默认只读取标题、网址和网页描述，也可开启正文读取。
- **少而必要地分组**：同一窗口至少 3 个明确匹配的标签才新建分组；已有组可以接收单个新标签。
- **查看判断结果**：标题下显示网页摘录，前三个候选按分数降序横向展示颜色、分组名和百分比。
- **延续已有分组**：浏览器重启后重新关联 Chrome 已恢复的分组，也支持接管手动创建的分组。
- **自选模型服务**：支持 Jev、OpenAI Decisions，以及 OpenAI / Anthropic 兼容的大模型服务和自定义地址。

## 安装

需要 **Chrome 140 或更新版本**，以及你自己的模型服务配置。

1. 前往本仓库的 [Releases](../../releases)，下载插件 ZIP 安装包。
2. 将 ZIP 解压到一个准备长期保留的文件夹。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后**直接包含 `manifest.json` 的文件夹**。
5. 将 AutoTabGroups 固定到工具栏，点击扩展图标打开侧边栏。
6. 在扩展详情中允许访问需要整理的网站；如果希望整理所有普通网页，将网站访问权限设为“在所有网站上”。

加载后请保留该文件夹。更新版本的方法见[安装与更新](docs/user-guide.md#安装与更新)。

## 开始使用

### 1. 配置模型

在“设置”中填写服务地址、模型名称和 API Key（服务要求时）。两项配置各有用途：

| 设置 | 用途 |
| --- | --- |
| 标签分类模型 | 点击“更新分组”时，判断网页应该加入哪个分类；可选决策模型或普通大模型 |
| 分类生成模型 | 使用“AI 生成分类”或“AI 生成描述”时生成建议；只手动管理分类时可以暂不配置 |

普通大模型和生成模型填写服务的基础地址；**Jev / OpenAI Decisions 填写完整接口地址**。具体示例见[模型配置](docs/user-guide.md#模型配置)。

普通大模型的思考强度默认关闭，可按型号调整。使用“保存并测试连接”会请求你配置的真实服务，可能产生费用。

### 2. 准备分类

在“分类”页选择一种方式：

- **手动添加**：例如“开发”“论文”“旅行”。描述可留空，也可点击“AI 生成描述”后编辑、保存。
- **AI 生成分类**：让模型根据未分组网页提出方案，检查并点击“采用分类方案”。采用方案只保存分类，归组由下一步执行。

已有分类列表也可以导入，示例见[分类管理](docs/user-guide.md#分类管理)。

### 3. 点击“更新分组”

选择当前窗口或所有普通窗口，再决定是否开启“读取网页正文”：

- **关闭正文读取**：使用标题、网址和网页描述，通常消耗更少的 token。
- **开启正文读取**：直接提取网页主要文本参与判断，不额外调用 AI 总结网页。

点击“更新分组”后查看结果。无法匹配的标签会保持未分组；详情中可以查看未归组或失败的原因。任务运行时可以取消，结束后可以撤销最近一次分组。

## 常见问题

**为什么有些标签没有归组？**

可能没有合适分类、分数或候选差距未达到设置要求，或同窗口只有一两个匹配标签、不足以新建分组。固定标签、无痕标签、已分组标签、被忽略的标签和浏览器内部页面不参与整理。可以查看“处理详情”，补充分组描述或调整设置。

**重复点击“更新分组”会重复调用 AI 吗？**

任务运行时不能重复启动。完成后再次点击，只处理仍未分组的标签；相同网页信息和配置会优先复用缓存。想重新请求模型，可以先在设置中“清除缓存”。

**会自动在后台整理吗？**

目前由你点击“更新分组”触发，不会持续自动归类新网页，也不会重排已经分组的标签。

**重启浏览器后怎么办？**

插件会重新关联 Chrome 已恢复或打开的分组，尽量复用已有组。它不负责重新打开已关闭的网页；若上次整理中断，请再次点击“更新分组”。

**能撤销吗？**

可以撤销最近一次任务。开始新任务会替换上一任务的撤销记录；已经关闭、跳转或被你手动重新分组的标签会跳过撤销。

## 数据与隐私

- 运行整理时，相关网页信息会发送到**你配置的模型服务**。关闭正文读取仍会发送标题、网址和网页描述。
- API Key、分类和设置保存在本机扩展存储中，不会通过插件同步密钥。
- 任务结果在本地保留网页标题、网址、分数及最多 160 字的摘录。
- 部分网页无法读取正文，例如浏览器内部页面、PDF 或复杂网页应用；此时会尽量使用可用的标题和描述。

更多说明见[数据与权限](docs/privacy.md)。
