# AutoTabGroups 0.1.3

本版围绕 Chrome 原生标签组重整了整理流程、侧栏与配置中心。整理始终由用户触发，优先复用当前窗口已有组，保留已经完成的手动分组。

## 三个明确的整理动作

| 动作 | 默认快捷键 | 行为 |
| --- | --- | --- |
| 整理当前页 | `Alt+1` | 将一个未分组页面加入已有组，不新建 |
| 更新分组 | `Alt+Shift+1` | 整理本窗口未分组页面；窗口完全没有组时初始化 |
| 更新并允许新建分组 | `Alt+Shift+2` | 先加入已有组，再为剩余页面分析新组 |

侧栏、网页右键与扩展图标右键使用相同命令。快捷键后台执行，不主动打开侧栏。AI 新建组至少需要三个明确成员；手动建组允许一个或两个页面。

已分组标签、固定标签、无痕与内部页面不参与自动整理。组内导航和手动移组不会重新分类；拖出组后在下一次手动整理时重新参与。任务应用前核对页面状态，避免覆盖用户期间的操作。

## 侧栏与配置中心

- 侧栏以“当前页面、本窗口整理、本窗口分组”三张卡片提供操作，可展开查看可整理页面和不参与原因。
- 三个整理按钮采用同级样式；提示使用短暂浮层，减少重复说明。
- 配置页在独立标签页打开，分为“常规、服务、高级”，与侧栏共用主题和控件。
- 最近整理移至“常规”，集中查看结果、候选分数、重新判断、失败重试、手动改分和撤销。
- 支持中文／English、浅色／深色／跟随系统；快捷键显示 Chrome 实际绑定。
- 更新工具栏与扩展管理页图标，统一详情展开、表单与弹窗交互。

## 模型与网页读取

- 标准 Chat 新增 OpenAI、Google Gemini、Anthropic（Claude）、DeepSeek、通义千问、Kimi、智谱预设，自动填写地址、协议与默认模型。
- 保留 OpenAI／Anthropic 自定义兼容服务，以及独立 Chat、Jev、OpenAI Decisions 归组后端。
- 默认只使用基本描述；正文模式可选内置读取、Tavily Extract 或 DeepSeek Fetch，远程读取凭据独立配置。
- 服务与高级设置共用待保存草稿；连接测试不保存，失败时保留输入。
- 分组说明按需自动补齐，已有说明不随成员变化重写；支持手动编辑和生成更新草稿。
- 改进多源元数据、动态页面身份核对、读取超时与本地兜底。

## 缓存、撤销与升级

分类缓存取消固定一小时过期，按实际输入和候选组语义判断有效性，保留当前会话最多 300 条。修改阈值可对缓存分数重新决策。

最近任务与撤销记录分离。无变更任务不覆盖旧撤销，部分成功后取消仍能撤销已完成部分。撤销尊重后续手动操作；浏览器新会话不复用旧 ID 执行任务或撤销。

升级保留已有模型配置、密钥与分组说明。旧的跨窗口范围和临时忽略语义不再用于新流程；历史记录与分数不重新计算。新增预设不会擅自替换旧配置。

## 安装与更新

需要 Chrome 140+。下载 Release 附件 **`auto-tab-groups-0.1.3-chrome.zip`**，解压后在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”。应选择直接包含 `manifest.json` 的目录，不能直接加载 ZIP 或 GitHub 的 Source code 压缩包。

已有用户将文件覆盖到原加载目录，再点击重新加载扩展并重新打开侧栏／配置页。建议先导出配置与说明；不要先卸载，导出文件不包含密钥。旧安装若未自动分配 `Alt+Shift+2`，请在 `chrome://extensions/shortcuts` 手动绑定。

扩展使用你自己的模型／读取 API，相关服务可能收费。详细使用步骤见 [README](https://github.com/Miraclexc/AutoTabGroups/blob/v0.1.3/README.md) 与[使用指南](https://github.com/Miraclexc/AutoTabGroups/blob/v0.1.3/docs/user-guide.md)，数据范围见[数据与权限](https://github.com/Miraclexc/AutoTabGroups/blob/v0.1.3/docs/privacy.md)。
