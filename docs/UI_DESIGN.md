# AutoTabGroups 界面设计与验收

## 选定方向

用户选择第 01 轮 A「精密工具」。北极星：把当前任务与下一步操作放在视线最近的位置。

侧栏是整理工作区；独立主页面是配置中心。共用视觉语言，不强行共用相同布局。保留插件名称与四格标记，钴蓝仅承担主动作和选中状态；Chrome 原生组的颜色独立表达组身份。

## 页面与状态范围

- 侧栏：当前页、普通批量与允许新建、本窗口组和成员；仅在运行时显示简短进度与取消，不再展示最近整理结果。
- 模态：编辑组、手动建组、手动改分、丢弃草稿、编辑冲突再次确认、导入差异预览。
- 配置：一级标签为常规、服务、高级。常规承载主题/语言、实际快捷键、最近整理与帮助；服务承载两个模型角色和网页读取；高级承载归组门槛、输入预算、读取兜底、思考参数、备份/缓存与诊断。最近整理默认收起，展开后保留全部结果、重试、手动改分、撤销和清除操作。服务与高级共用一份草稿和明确保存；常规偏好即时保存。
- 状态：加载、无模型配置、无组、无候选、已分组、受保护/固定页、运行中、部分成功、失败、取消、旧会话结果、保存失败和冲突。

## 视觉规范

源头为 `src/ui/styles.css` 的语义变量，页面布局分别位于 `sidebar.css` 与 `configuration.css`。

- 字体：Segoe UI / Microsoft YaHei / system-ui；正文14px，辅助13px，快捷键12px。标题按任务层级使用17px和24px，避免装饰性大标题。
- 浅色：白色内容面、冷灰背景、石墨文字、钴蓝操作；深色：深石墨底、蓝灰内容面、浅蓝强调，不用整体反色滤镜。
- 布局：三标签为唯一一级导航，支持方向键/Home/End。常规参数使用统一两列设置行，窄屏上下排列；复用服务和读取兜底开关遵守相同对齐。连接状态/测试、最近整理、快捷键管理和数据维护采用独立功能卡片，参数本身不套卡片。
- 侧栏：当前页使用接近白色的冷色内容面，窗口整理使用轻微蓝色，原生组管理使用轻微绿色。文字与操作名称仍承担识别，色差只辅助导向，原生分组颜色保持独立。
- 圆角：控件7px，侧栏功能卡片10px，模态12px；卡片内普通列表使用留白/单一分隔线，不层叠卡片。
- 主要控件至少36px高；焦点使用2px描边和3px偏移。标签文字与状态不只靠颜色区别。
- 长标题允许换行；收起的组描述可截一行，展开后完整可读；模态主体滚动，操作区稳定可达。
- 图标采用一套20px画布、1.45px描边的本地线性符号；不引入图标字体、网络资源或媒体请求。
- 手势手感：按下1px/100ms、状态150–180ms、模态7px/180ms进入。首次当前页轻微进入，展开与反馈呼应；遵守 reduced-motion。

## 语言与偏好

默认中文、跟随系统；支持 English、浅色、深色。偏好通过后台验证并串行保存到 `ui.preferences.v1`；与模型配置版本分开，外观变化不会重置模型草稿。存储失败保留原设置，明确反馈。

UI 固定文案和应用产生的结果/错误可本地化。用户组名、网页标题、原始模型内容不做机器翻译，历史任务数据不重写。右键动作与后续任务的图标提示也跟随界面语言。

## 验收方法

使用隔离 Chromium、项目 Playwright 和本地 mock 服务。真实扩展页操作与原生分组一起验证；不访问用户 Chrome 配置，不请求真实付费模型。

逐页覆盖中英、深浅、宽窄布局；验证偏好同步与重新加载、字段草稿/测试/失败、模态焦点与 Escape、长文本、任务和手动操作。截图作为 Subagent 的独立评审依据，按发现修正并复验。具体轮次、结果及边界见 `UI_REVIEW.md`。

200% 检查包含 CSS zoom 与 200×450 CSS 视口重排（对应 400×900 侧栏放大至 200% 的可用空间）；2 倍像素截图仅用于细节检查，不能替代布局放大。所有浏览器验收使用临时配置与本地 mock，不证明用户桌面的 OS 快捷键投递、实际模型服务或全部 Chrome 外壳交互。

## 侧栏卡片布局（2026-10-21）

延续 A「精密工具」，北极星：一张卡片对应一类任务，一眼找到当前状态、整理操作和已有分组。三张卡片依次为“当前页面”“本窗口整理”“本窗口分组”；蓝色主按钮仍是主要视觉焦点。保留原生组的列表展开与颜色识别，不给组、成员、说明再套卡片。

背景沿用全局底色，卡片沿用内容面与细边框，无重阴影和新配色。卡片由父布局统一管理 10–12px 间距，320px 下减少外围留白，保留 13–15px 正文／标题与完整操作区域。精简范围说明与批量动作说明，后者按两句分行，避免中文孤立尾字；任务逻辑、设置页和最近整理的归属不变。沿用按钮按下、分组展开和当前页进入动效，不增加卡片悬浮、弹跳或持续动画。

验收关注：320/400px、中英文、深浅主题、长标题／组名、空状态、加载与取消、展开成员、手动建组弹窗及 200% 重排。原版基线见 `output/playwright/ui/activity-move/`。本次不需要额外图片素材。

## 模型服务与网页读取合并（2026-10-21）

参照 LaterOn 的模型配置设计稿，将读取能力和判断能力区分清楚，同时保持本项目单页保存与既有视觉。普通流程顺序为标准 Chat、归组判断、网页读取；网页读取先选基本描述或正文，正文再选内置／Tavily／DeepSeek。远程读取显式配置端点、密钥和测试。进阶参数移到独立的“高级”一级标签，日常服务配置中不展开；包含归组阈值、正文与请求预算、读取超时／深度／兜底，以及两个 Chat 角色的思考控制，每个字段附用途说明。

沿用主题、字号、表单和焦点规则，不增加装饰素材或动效。侧栏卡片与最近整理位置不变。


## 三层混合布局（2026-10-21）

沿用 A「精密工具」，一级导航收敛为顶部三个标签：常规、服务、高级。主题和语言用普通下拉选择；模型、读取器和进阶参数按一致的标签列／控件列排列，窄屏改为上下排布。连接状态与测试、快捷键管理、最近整理、备份和本机数据才使用功能卡片。最近整理默认收起，依旧只保留最近一次任务。

服务和高级共用草稿、测试失效状态、版本冲突判断及保存操作；切换标签不会保存或丢弃输入。默认打开常规，未配置模型时直接提供前往服务的卡片；服务底部提供高级参数入口。标签支持方向键、Home／End，切换后焦点保持在标签；正文不额外增加整页键盘停靠点。

侧栏保留当前页、窗口整理和分组管理三张卡片，内容面分别轻微偏冷白、蓝、绿。色差只辅助区分任务，原生分组自身颜色不受影响，窗口整理仍仅一个主要按钮。


## 数据区域精简与说明位置（2026-10-21）

移除侧栏底部的数据发送说明；侧栏只保留功能卡片及必要运行状态，卡片列表底部保留18px留白。必要说明位于“高级 → 数据与诊断 → 数据发送与本机存储”，默认收起，并准确覆盖整理、主动更新说明、远程读取和连接测试。

数据区域将配置备份与分类缓存两项维护操作分为紧凑并列卡片；760px以下纵排，480px以下按钮纵排。标题与辅助图标形成同一基线，动作放在卡片底部；未保存配置导致导入不可用时，原因放在动作前。使用帮助继续留在常规，最近整理的查看、撤销和清除仍在常规的最近整理卡片中。


## 统一折叠入口（2026-10-21）

所有折叠项复用 DisclosureSummary，保留原生 details/summary 的状态和键盘行为，移除浏览器默认实心三角。标题在左、16px线性箭头在右；收起朝右，展开朝下并使用强调色，悬停轻微着色，键盘焦点沿用共享描边。普通入口至少44px，次级详情和排除项使用32px紧凑规格。数据说明和诊断形成连续分隔行，帮助问答使用同一行式入口；最近整理、任务结果、判断详情、撤销上下文和原生分组展开一并统一。只调整组件呈现，不改变默认展开状态或业务逻辑。箭头150ms转向，遵循 reduced-motion。

## 本窗口整理的页面范围（2026-10-21）

卡片默认只显示“可整理”和“不参与”两个数量按钮，沿用细边框、右侧线性箭头及选中强调色。任一按钮展开下方清单，再点收起；两份清单不同时展开，不增加解释段落。两个数量覆盖当前窗口全部标签；可整理直接采用后台资格判断，不参与包含已分组、固定、浏览器内部和不支持页面。逐页显示标题，可整理页附域名，不参与页附简短原因；已分组页同时显示组名。

清单按原生标签顺序排列，高度不超过260px或35vh，超出时独立滚动，整理按钮留在清单外。标题最多两行，悬停可查看全名，原因单独保留；280px以下两个数量入口上下排列。Enter／空格切换，Escape收起并返回当前入口焦点；清单本身可用键盘滚动。标签状态变化同步更新数量、清单和原因；查看范围不调用模型，不改变实际整理规则。

## 正文读取的渐进配置（2026-10-21）

“服务 → 网页读取”以“读取网页正文”复选框作为入口，沿用常规参数的对齐设置行。未勾选时只保留一行简短说明，隐藏读取器和API字段；勾选后显示正文读取方式，默认本地内置读取器，选择Tavily或DeepSeek后再显示该服务的接口、密钥及连接测试卡片。开关不清除读取器选择、地址或密钥草稿；仍与模型共用明确保存操作。复选框支持标签点击与空格操作，并关联受控区域和辅助说明；不增加卡片、动效或新的导航层级。

## 标准Chat服务的平台预设（2026-10-21）

仅标准Chat服务的“接口协议”改为“服务平台”。七个常用平台与两种自定义兼容方式在同一下拉框中分组呈现；预设平台隐藏手填地址，提供官方文档链接和可修改的默认模型。常规参数仍用现有设置行，连接测试仍用现有功能卡片，不增加一级导航或新样式。使用低档思考的预设在模型字段下明确说明，高级设置保留细调。独立归组Chat继续保留协议、地址和型号配置。

平台标识是可选配置字段，旧设置及任务快照不补写默认平台；读取旧数据仍显示为自定义方式。预设身份同时核对协议与地址，外部改写过的地址不能误显示为官方平台。切换到不同域名时要求新平台密钥，测试／保存沿用现有草稿、失败反馈和并发保护；侧栏对缺少Key的预设提供配置入口。
