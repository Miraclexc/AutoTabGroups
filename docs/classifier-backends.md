# 分类后端

入口：设置 → 标签分类模型 → 分类后端。生成分类方案和更新标签归属分别使用各自的模型配置。

| 后端 | Base URL 示例 | 地址处理 | 模式 |
| --- | --- | --- | --- |
| Jev | `https://api.typesafe.ai/v1/systemone` | 原样请求 | 原生 choice |
| OpenAI Decisions | `https://api.openai.com/v1/decisions` | 原样请求 | 原生 choice，模型 `gpt-6-luna` |
| 普通大模型 · OpenAI 兼容 | 服务商版本路径 | `/chat/completions` | JSON 分类，需支持 `response_format: json_object` |
| 普通大模型 · Anthropic 兼容 | `https://api.anthropic.com/v1` | `/messages` | 最终文本中的 JSON 分类 |

截至 2026-10-19，[OpenAI Decisions 官方文档](https://developers.openai.com/api/docs/guides/decisions)列出该接口处于 public beta，支持 `gpt-6-luna`。接口协议与 Chat Completions 不同：输入使用 `input`，问题为数组，每个 choice 问题提供 `name`、`instructions` 和 `choices`；返回 `answers` 数组及候选概率数组。插件将它们映射到本地稳定分类 ID。没有把它当作普通聊天模型调用。

切换后端只改变调用方式，保留地址、模型名和已存密钥。请检查这三项后保存或测试；新后端不会自动获得另一家服务的正确配置。当前仍只有一套分类端点配置和一把分类密钥；不支持多套后端配置同时保存。旧配置默认迁移为 Jev。决策模型的地址不自动追加或补全路径，末尾斜杠也保持原样；旧地址若只有 `/v1`，需要手动补全为服务要求的完整接口 URL。普通大模型仍按所选聊天协议追加路径。

普通大模型可选 GPT、Claude、DeepSeek、GLM、Kimi 等对应兼容服务，并独立设置思考适配方式和强度，默认关闭。生成模型的强度不会传入分类请求；Jev 和 Decisions 都不发送普通聊天模型的思考参数。型号限制见 [思考设置](model-thinking.md)。

每次判断都提供页面标题、URL、描述，以及用户启用时的 Readability 正文；直接分类，不生成页面摘要。所有分类的名称、描述、包含和排除条件同时传入。候选仅额外含 `none`，统一表示没有合适分类或信息确实不足，允许页面保持未分组。

三种后端共用语义规则：标题和 URL 足够明确时即可分类，不因缺少正文、空描述或提取失败直接拒绝；允许中英文、同义词和子主题匹配，避免偶然关键词或同域名造成误归组。名称和描述共同界定范围，名称单独提供时按通常含义判断；包含项是非穷尽示例，排除项是明确边界。多个候选相关时优先直接、具体的匹配，分数应反映实际不确定性，不为通过阈值虚增分数。本次提示词和候选集更新会使旧分类缓存失效，下次更新重新判断；历史任务记录保留。

Jev / Decisions 使用接口返回的候选概率；普通大模型使用提示词要求的归一化自评分。后者在结果中显示“模型自评分”，不能视为经过校准的概率或真实正确率。最低分数、第一与第二名分差均参与自动归组；`confidence` 不替代候选分数。两个决策接口的概率也需结合实际样本评估阈值。

响应必须包含完整候选分布、合法取值、总和约为 1，以及与最高分一致的选择。拒绝回答、截断、无效 JSON、未知分类或非法分数会让该条记录失败并保持未分组，其他页面继续处理；不会静默切换后端。明确不匹配及低分在页面上统一显示为未匹配，统计合并计算；具体原因仍可在处理详情中查看。

缓存键包含后端、协议、地址、模型、思考配置、页面和分类规则；切换会使用不同缓存。缓存保存分数来源，读取缓存后仍区分自评分与概率。

验证全部使用 mock：`tests/classifiers.test.ts` 校验协议和异常边界，`tests/workflow.test.ts` 验证缓存隔离；浏览器脚本实际通过设置 UI 切换三种后端、两种聊天协议，并对 Chrome 标签执行增量归组。`npm run mock:server` 支持全部四种路径，只使用固定规则，不代表真实语义效果。

更新结果展示实际分类中分数最高的三个候选，横向一行按原始分数降序显示“颜色方块 分组名 百分比”，不对前三名重新归一化；不把 none 当作分组列入前三。少于三个分类时显示实际数量。分数、当时的分类名和颜色随任务记录保存，颜色优先跟随当前分类；分类已删除时使用保存的颜色，旧记录缺失颜色时使用灰色。长名称省略显示，悬停可查看完整名称、分数及分数来源。失败未获得响应、旧任务未保存分数时显示暂无候选分数，不伪造零分。
