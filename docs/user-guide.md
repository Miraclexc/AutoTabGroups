# 使用指南

[返回 README](../README.md)

## 安装与更新

插件安装包由本仓库的 [Releases](../../../releases) 提供。下载发布附件中的插件 ZIP，解压后在 Chrome 的 `chrome://extensions` 页面启用开发者模式，选择“加载已解压的扩展程序”。应选择直接包含 `manifest.json` 的目录，而不是 ZIP 文件或源码目录。

建议将解压目录放在固定位置。更新时先等待当前任务完成，或主动取消任务，再将新版解压到原目录并替换扩展文件，随后在 `chrome://extensions` 中点击该扩展的重新加载按钮。保留原目录和扩展记录有助于延续设置；不要先卸载扩展，卸载会清除其本地数据。重要分类可提前导出备份，导出不包含密钥。

## 模型配置

“标签分类模型”用于更新分组；“分类生成模型”用于 AI 生成分类及 AI 生成描述。两者分别保存地址、模型和密钥，可以使用不同服务。

以下为插件的地址填写方式，实际模型名称和可用接口以你的服务提供方为准：

| 类型 | 地址填写示例 | 插件如何使用 |
| --- | --- | --- |
| 生成模型 / 普通大模型，OpenAI 兼容 | `https://api.openai.com/v1` | 追加 `/chat/completions` |
| 生成模型 / 普通大模型，Anthropic 兼容 | `https://api.anthropic.com/v1` | 追加 `/messages` |
| Jev | `https://api.typesafe.ai/v1/systemone` | 完整地址，原样请求 |
| OpenAI Decisions | `https://api.openai.com/v1/decisions` | 完整地址，原样请求 |

支持自定义 HTTP(S) 网关和本地服务地址。切换分类后端会保留已填写的地址和模型名，请检查它们是否适合新后端；插件不会自动替换成另一家服务的配置。旧版决策模型地址如果只填到 `/v1`，需要手动补全。

普通大模型可使用 GPT、Claude、DeepSeek、GLM、Kimi 等兼容服务，具体可用性取决于服务协议和型号。OpenAI 兼容服务需要支持 JSON 输出。遇到连接失败，先检查地址、密钥、模型名称及接口协议，再查看错误提示。

思考强度默认关闭，生成与分类分别设置。有些型号不支持关闭，插件会提示选择可用强度或更换模型，不会自动开启。Jev 和 OpenAI Decisions 不使用普通大模型的思考设置。详细兼容规则见[思考设置](model-thinking.md)。

“保存并测试连接”只发送虚构样例，不读取真实网页，但会调用当前配置的服务，可能产生费用。测试通过表示本次请求及响应格式可用，不代表真实网页一定能正确分类。

## 分类管理

可以只填名称，也可以添加描述、包含示例、排除条件和颜色。描述适合解释分类范围，名称尽量简短；包含项是示例，不要求网页逐条满足，排除项用于限定边界。

“AI 生成描述”只发送分类名，结果仍需你保存才会生效。“AI 生成分类”读取当前范围内的可处理网页，生成可编辑方案；点击采用后合并到分类列表，同名分类更新描述。模型也可以建议不新增分类。

最简导入内容：

```json
[
  { "name": "论文" },
  { "name": "开发" }
]
```

含描述和边界的示例：

```json
[
  {
    "name": "插件开发",
    "description": "浏览器插件开发、调试与发布所需的文档和讨论。",
    "include": ["Manifest V3", "Chrome 扩展 API"],
    "exclude": ["普通浏览器新闻"],
    "color": "blue"
  }
]
```

导入会替换分类定义，请按需先导出备份；它不会移动已有标签。与导入不同，采用 AI 方案会合并分类。需要让新标签加入手动创建的 Chrome 分组时，可以在“接管现有 Chrome 分组”中选择对应分类。

## 整理结果和分数

标题下是最多 160 字的网页摘录，正文关闭时显示网页描述；没有可用文本时显示占位提示。摘录直接来自网页，不是模型总结。

候选行显示最多三个真实分组，按原始分数降序排列。颜色跟随当前分类；长名称省略显示，悬停可查看完整名称及分数来源。

- **已归组**：本次已加入对应 Chrome 分组。
- **未匹配**：没有合适分类、信息不足，或分数/候选差距未达到要求。原“待判断”合并到此项。
- **已跳过**：例如只有一两个匹配标签，尚不足以新建分组，或操作前标签状态发生变化。
- **失败**：读取、服务请求或分组操作发生错误，详情中保留提示。

“自动归组最低分数”可设置为 0～1，默认 0.8；最小候选差距默认 0.2。降低最低分数后，最小差距规则仍会生效。候选分数还包含不归组的 `none` 选项，因此界面显示的前三个分组百分比不一定相加为 100%。

普通大模型返回的是自评分，不是实际正确率；决策模型分数也需要结合实际效果判断。详细说明见[分类后端](classifier-backends.md)。

## 重复更新、恢复与撤销

更新只扫描未分组标签，任务运行时不能重复启动。每次都会重新读取页面信息，相同输入和配置优先使用当前浏览器会话内、有效期一小时的缓存；需要重新调用模型时可先在设置中清除缓存。

插件会尽量复用同窗口已关联的分组。同窗口同类别至少三个明确匹配标签才新建分组；已有分组可以接收单个标签。多个窗口分别整理，不会把不同窗口的标签凑到一起。

重启后只会关联 Chrome 已恢复或打开的分组，不负责恢复关闭的网页。手动修改分组名称时会尽量保留关联；删除 Chrome 分组不会删除插件中的分类定义。同名组含义不一致或关联不明确时，可手动接管。

浏览器关闭时尚未完成的任务，在下次启动后会标记为中断；请重新点击更新。撤销只覆盖最近一次任务，开始新任务会替换上一任务的撤销记录。撤销会跳过已关闭、跳转或被手动重新分组的标签。

## 读取不到网页内容

确认扩展具有目标网站的访问权限。浏览器内部页面、扩展商店、复杂网页应用、PDF、视频及嵌入页面可能无法提取正文。休眠、冻结或加载中的标签不会被自动唤醒，插件会尽量使用标题和网址。必要时先正常打开网页、等待加载，再重新更新。
