# 使用指南

[返回 README](../README.md)

## 入口与处理范围

所有操作仅处理触发窗口。工具栏图标打开侧栏；侧栏中的配置按钮打开或复用独立配置页。

- **整理当前页 / Alt+1**：当前页未分组时匹配已有组；已经在组内就跳过。无组时侧栏说明原因并停用该按钮，快捷键会提示可手动建组或批量初始化，不创建单页 AI 组。
- **更新分组 / Alt+Shift+1**：只加入当前窗口已有组。窗口没有任何实际组时自动初始化；历史说明不算实际组。
- **更新并允许新建分组 / Alt+Shift+2**：先匹配已有组，再为剩余标签找新组。

快捷键不会打开侧栏。角标与悬停文字显示运行结果。右键与侧栏执行相同命令。默认按键与 LaterOn 冲突时，请在 `chrome://extensions/shortcuts` 调整。

## 模型配置

主页面提供配置与最近整理记录。顶部三个标签为“常规、服务、高级”，宽窄窗口采用相同导航。常规管理主题、语言、快捷键、最近整理与帮助；服务管理模型和网页读取；高级管理判断参数、预算、思考参数及数据诊断。普通设置对齐排列，独立操作使用卡片。模型与读取设置在切换分区后保留未保存草稿，需要点击底部“保存配置”；重新载入时会确认放弃草稿。

配置页始终在独立标签页中打开。重新加载扩展后，请关闭旧的嵌入式配置窗口，再从侧栏“打开配置”进入；不需要卸载扩展或清空配置。

标准 Chat 服务必须配置，用于说明和新组建议。归组判断可以复用该服务，也可选择独立 Chat 或现有决策后端。

标准 Chat 的“服务平台”提供OpenAI、Google Gemini、Anthropic（Claude）、DeepSeek、通义千问、Kimi和智谱预设。选择平台后会填写地址、协议和默认模型，输入该平台API Key即可测试与保存；模型名称仍可修改。旧配置继续按自定义兼容服务显示，不自动覆盖地址、模型和密钥。

| 平台（官方接口说明） | 默认模型 | 连接方式 |
| --- | --- | --- |
| [OpenAI](https://developers.openai.com/api/docs/models/gpt-5.4-mini) | `gpt-5.4-mini` | OpenAI Chat Completions |
| [Google Gemini](https://ai.google.dev/gemini-api/docs/openai) | `gemini-3.8-flash` | 官方OpenAI兼容接口 |
| [Anthropic · Claude](https://platform.claude.com/docs/en/models/overview) | `claude-sonnet-5-5` | Anthropic Messages |
| [DeepSeek](https://api-docs.deepseek.com/) | `deepseek-flash` | OpenAI兼容接口 |
| [通义千问 · 百炼](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope) | `qwen-plus` | 中国内地OpenAI兼容接口 |
| [Kimi · 月之暗面](https://platform.kimi.com/docs/api/chat) | `kimi-k3` | 中国内地OpenAI兼容接口 |
| [智谱 · GLM](https://docs.bigmodel.cn/cn/guide/start/quick-start) | `glm-5.3` | 中国内地普通API的OpenAI兼容接口 |

预设核对日期为2026-10-21；模型能否调用取决于账号权限及平台后续调整，可修改为账号可用的型号。Gemini、Claude、Kimi和GLM预设使用低档思考，界面会说明，可在高级设置调整；不能关闭思考的型号会阻止不兼容请求。千问预设使用其专用思考开关。国际区域、代理、业务空间专属地址或Coding套餐使用下方自定义兼容服务配置。

选择预设时若服务域名改变，当前草稿不沿用旧平台密钥，需要填写新平台Key；保存之前不会修改原配置。返回原服务可继续使用原来保存的密钥。测试不会保存，错误或保存失败会保留平台、模型与密钥输入。清除密钥后仍可保存，但预设平台没有Key时不会发起模型请求。

| 类型 | 地址格式 |
| --- | --- |
| OpenAI 兼容 Chat | 基础地址含版本路径，如服务地址 `/v1`；追加 `/chat/completions` |
| Anthropic 兼容 Chat | 基础地址含版本路径；追加 `/messages` |
| Jev / OpenAI Decisions | 完整接口 URL，按原样请求 |

自定义兼容服务保留手填地址、模型及原有密钥管理方式；独立归组服务配置不变。Chat 与归组连接测试发送虚构样例，测试成功不代表真实分类一定正确。测试不保存；“保存配置”不强制先联网测试。修改相关草稿后需要重新测试。

空密钥输入保持已有密钥；明确点击清除后保存才会删除。保存失败保留输入。运行整理时可以编辑配置草稿，但必须等任务结束才能保存或测试。外部修改发生冲突时请重载已保存配置，重载会提示放弃草稿。

## 网页读取与高级设置

网页读取位于“服务”标签，与两个模型角色共用草稿和“保存配置”。切换到“高级”继续调整参数时也保留同一份草稿，两个标签均可保存全部修改。旧的 #models 和 #reading 地址仍会进入服务标签。

默认不勾选“读取网页正文”。勾选后立即显示“正文读取方式”，选择内置读取器、Tavily Extract或DeepSeek Fetch；选择远程服务后显示对应接口、API Key和连接测试。取消勾选会收起配置并使用基本描述，保留已选读取器及已填内容。修改后点击“保存配置”生效，连接测试不会保存。

- **基本描述（默认）**：仅标题、清理后的网址和摘要，不扫描正文，不请求远程读取服务。
- **网页正文 / 内置读取器（本地提取）**：读取当前已加载页面，排除表单与可编辑区域；没有正文时使用基本描述，无需额外 API。
- **网页正文 / Tavily Extract**：填写完整提取接口与独立密钥；高级设置可选择标准／深度提取。
- **网页正文 / DeepSeek Fetch**：填写完整 Fetch 接口与独立密钥，不使用 Chat 接口，也不自动复用模型密钥。

远程服务只收到清理后的网址，不附带浏览器 Cookie；登录页面的远程版本可能与当前页面不同。读取结果会被截断，再交给所选归组模型。页面在等待期间关闭、导航或变更分组时，不使用过期结果。

“测试读取接口”仅请求公开 example.com，不读取当前标签，不保存配置，也不会用本地兜底掩盖失败；可能产生服务费用。Tavily 与 DeepSeek 的地址和密钥分别保留，密钥不进入导出或任务记录。连接测试使用当前草稿；修改字段后旧测试结果失效。

进阶参数集中在“高级”标签，日常连接配置中不展开。每个字段在界面中标明用途：

| 项目 | 默认值与作用 |
| --- | --- |
| 最低归组分数 | 0.8；最佳候选低于此值时保持未分组，调高更保守 |
| 最小候选分差 | 0.2；与其他候选（包含无合适组）差距不足时不归组 |
| 单次最多建议新组数 | 8；仅限制建议数量，不放宽至少 3 页的建组门槛 |
| 每页正文字符上限 | 6000；统一限制本地与远程正文长度 |
| 请求输入预算 | 30000 UTF-8 字节；控制请求输入大小，不是精确 token 数 |
| 远程读取超时 | 20 秒；限制本次请求等待时间，不增加自动重试 |
| Tavily 提取深度 | 标准；深度适合复杂页面，可能更慢且消耗更多服务额度 |
| 远程失败时使用本地读取兜底 | 默认开启；依次尝试本地正文、基本描述；关闭则该页读取失败，不继续分类。取消不会触发兜底 |
| 思考参数适配与强度 | 默认自动适配、关闭；控制普通 Chat 的思考字段和预算，不调整归组门槛。独立 Chat 可单独设置 |

正文选项同样作用于生成组说明的参考页。旧配置缺少读取服务字段时沿用本地读取，不擅自开启正文或远程服务。

官方接口：[Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)、[DeepSeek Fetch](https://api-docs.deepseek.com/zh-cn/api/fetch/)。

## 外观与语言

在“常规 → 外观与语言”选择浅色、深色或跟随系统，以及中文／English。默认跟随系统、中文。每次修改立即保存并同步到已打开的侧栏与配置页，不改变模型草稿、已有分组名称或网页内容。保存失败时保留原偏好并显示重试说明。

键盘可访问所有操作：Tab 在控件间移动，Enter 激活按钮或展开详情；弹窗内焦点保持在弹窗中，Escape 关闭，存在未保存编辑时先确认。系统开启减少动态效果时，界面关闭非必要过渡。

## 已有组与说明

插件分组使用已保存说明。其他 Chrome 原生组在首次需要时自动补齐说明，无需接管。

参考组内最多 5 页，按照成员顺序均匀取样；遵循正文开关。说明失败时停止整理，不隐藏该组，也不会因此当作零组新建。

侧栏可编辑名称、颜色、说明。“根据组内网页更新说明”只生成草稿，保存后生效；成员变化不会自动覆盖说明。

同名组仍是独立对象。组关闭后说明保留，但不自动恢复网页，也不让历史说明成为当前归组目标。

## 新建、手动纠正与结果

侧栏“本窗口整理”中的“可整理”和“不参与”数量均可点击，展开对应的逐页清单，再点收起。两项合计为当前窗口全部标签；不参与页标明已分组及组名、已固定、浏览器页面等原因。清单默认收起，展开不会调用模型，页面多时可在清单内滚动。

侧栏只显示当前页、整理入口、本窗口分组和运行中的简短进度／取消，不保留最近整理区块。手动建组入口统一放在“本窗口分组”。

在配置页的“常规 → 最近整理”卡片中展开后查看最近一次结果、判断详情，重试失败页或手动改分；清除详情也在这里，不会改变分组或撤销记录。只保留最近一次任务，不累积历史。自动整理没有移动标签时会明确说明，而不会暗示所有页面已归组。结果带有操作时间，详情是那次任务的记录；之后的手动移动不改写旧记录。撤销使用卡片外的独立按钮，显示涉及页数和所属窗口，悬停可查看操作时间。

AI 建组需要最终至少 3 个仍可操作的明确成员；不够就保持未分组。手动建组可勾选至少 1 页，填写名称、颜色和可选说明，不依赖模型。

结果分为已归组、保持未分组、跳过、失败。详情展示网页摘录和最多三个原始候选分数。分数为接口概率或模型自评分，不等于正确率。

最低分数默认 0.8，最小候选分差默认 0.2，可在高级设置调整。判断不足、无合适组及数量不足均不会强制归组。

“手动改分”选择当前窗口已有组，不调用 AI。“重新判断”绕过该页缓存。“重试失败项”保留原动作的新建权限，不扩大操作范围。

## 标签变化

分组内导航、分组内新开标签、手动 A 到 B 都不触发分类。新标签如果实际落在组外，下次手动更新时参与。拖出组的标签也重新参与并尝试缓存。

任务只处理启动时的候选。期间新开的页面等下次；关闭、导航或被用户分组的候选在应用前跳过。固定、无痕和内部页面不参与。

## 读取、缓存和撤销

轻量读取使用页面元数据与实时标题，不通用扫描正文拼摘要。开启正文后使用 Readability 并限制长度。休眠、冻结或权限不足时尽量退回标题和 URL，不强行唤醒。

缓存不按时间过期，按网页信息、模型配置和候选含义识别；最多 300 条、仅当前浏览器会话。阈值变化会重新应用到原始分数。命中也仍检查真实标签与目标组。

侧栏在“本窗口分组”下方、内容末尾提供独立的“撤销最近一次分组”按钮；配置页“常规”也在“最近整理”卡片外提供同一入口。窗口批量整理、单页加入分组、插件内手动建组或改分均可撤销，两个入口针对同一条最近实际成员变更记录，并非各自保留一次撤销。按钮旁显示涉及页数及当前／其他窗口。没有可撤销记录或当前操作尚未结束时，按钮不可用。新任务没有变更就不覆盖旧撤销；取消或部分失败后也能撤销已经完成的部分。已关闭、导航或被用户改分的标签保持现状。旧浏览器会话不能执行撤销。

## 导入导出与升级

导出配置与说明，不含密钥、原生标签／组 ID 或完整正文。导入先显示差异，确认后合并说明并更新配置；不会移动标签或打开网页。预览后数据变化需重新预览。

升级保留旧设置和说明，包含／排除信息作为语义资料保留。旧全窗口范围和临时忽略不再生效。旧记录只读，不重新计算分数。不要先卸载扩展，卸载会清除本地数据。


数据维护位于“高级 → 数据与诊断”：配置备份与分类缓存各有独立操作卡片。网页信息发送范围、密钥存储及会话缓存说明默认收起在“数据发送与本机存储”中，不再占据侧栏。
