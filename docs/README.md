# AutoTabGroups 文档

AutoTabGroups 使用你配置的模型服务理解网页，将标签整理到 Chrome 原生分组。你决定什么时候整理、是否读取正文、能否建立新组，并可随时手动调整归属。

这里同时提供使用说明和开发者参考，描述项目当前的功能与实现。
