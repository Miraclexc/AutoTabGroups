# 常见问题与排查

[文档首页](README.md) · [使用指南](user-guide.md)

## 页面没有被归组

先在侧栏展开“不参与”，确认页面不是已分组、固定、无痕或浏览器内部页面。自动整理仅处理触发窗口中的未分组 HTTP(S) 页面。

再到“常规 → 最近整理”查看具体原因：

| 结果 | 可以怎么处理 |
| --- | --- |
| 没有合适组 | 检查组名和说明是否覆盖该主题；必要时手动建组，或选择允许新建的动作 |
| 候选分数或分差不足 | 查看前三个候选，明确重叠组的说明，或适当调整高级设置中的门槛 |
| 相关页面不足三个 | AI 不额外新建组；可选择至少一个页面手动建组 |
| 跳过 | 页面可能已关闭、导航或被手动移组，按最新状态重新整理 |
| 失败 | 根据错误检查模型、读取服务或页面权限；修正后重试失败项 |

正文缺失本身不代表不能分类。标题和网址已经明确时，模型仍可选择已有组。候选分数不是正确率，具体解释见[分类接口说明](classifier-backends.md)。

## 窗口有分组，但“更新分组”没有新建组

这是该动作的范围：窗口已有组时只匹配已有组。需要为剩余页面建立新组，请使用“更新并允许新建分组”。窗口完全没有实际分组时，“更新分组”才允许初始化；“整理当前页”始终不会新建组。

## 测试连接失败

| 现象 | 检查项 |
| --- | --- |
| HTTP 401 / 403 | 对应服务的密钥、账号权限，以及是否切换了平台却未更换密钥 |
| HTTP 404 | 地址、版本路径和所选协议；普通 Chat 填基础地址，决策接口填完整路径 |
| HTTP 400 | 模型名、协议、思考适配与强度是否被所用服务支持 |
| HTTP 429 | 服务额度或请求限制，稍后再试 |
| 超时或无法连接 | 服务可达性、代理配置与响应速度；较强思考可能增加等待时间 |
| 响应格式不正确 | 网关是否返回所选协议要求的结构；普通 Chat 分类需要 JSON 输出 |

连接测试使用当前草稿，成功后仍需点击“保存配置”。测试只证明这次样例请求完成，不能保证每个网页都能正确归组。插件不会在服务报错后悄悄切换模型或移除思考参数。

## 为什么选择“关闭思考”仍被提示不能使用？

部分型号必须思考，部分网关不接受当前控制字段。插件会阻止已知不兼容请求，不自动替换模型或将“关闭”改成“开启”。检查高级设置中的适配方式和型号提示，明确选择支持的档位，或使用能关闭思考的模型。详见[模型思考设置](model-thinking.md)。

## 正文读不到，或者与浏览器里看到的不一样

内置读取器读取已加载的主要文本，复杂应用、休眠页面或受限页面可能无法提取。先确认“服务 → 读取网页正文”已开启，并查看结果中的读取来源。

远程读取只获得网址，没有浏览器登录 Cookie，所以可能返回登录页、公开版本或空内容。对依赖登录态的页面可改用内置读取器。远程失败时是否继续本地读取，由高级设置中的兜底选项决定。

## 关闭侧栏、关闭浏览器或意外退出会怎样？

关闭侧栏不会主动取消后台任务，可重新打开查看。浏览器仍在同一会话时，扩展后台被挂起后可按已保存进度恢复。

浏览器完全退出或意外关闭后，下次启动不会让上次未完成任务继续操作新的标签 ID。插件识别浏览器实际恢复的组并重新关联说明；它不代替浏览器的会话恢复功能。

已经完成的归组可能保留下来，最后一次操作是否完成需要以实际标签状态为准。浏览器操作和本地记录并非一个原子事务，不能保证崩溃瞬间的每个操作都完整记账。检查当前分组后重新整理即可；跨浏览器会话不提供旧操作撤销。

## 同名组会重复建立或合并吗？

已有组按实际浏览器身份分别处理，名称相同也不会合并。重启后的说明关联只使用无歧义的名称或历史名称匹配；不能确定时会建立独立说明记录，不因缺少关联额外创建浏览器组。

## 重复点击更新，会重复付费吗？

同一时间只允许一个整理任务。任务结束后再更新，只处理当时仍未分组的页面。相同页面信息、模型和候选组可能命中会话缓存，但新内容、说明补全、新组规划或主动“重新判断”仍可能发起请求，因此不能保证不产生费用。

## 快捷键没反应

在 `chrome://extensions/shortcuts` 确认实际绑定，检查是否与系统或其他扩展冲突。也可以用侧栏按钮或右键菜单执行同一个动作。“高级 → 数据与诊断”中的快捷键任务诊断可帮助判断扩展是否收到命令；未收到命令不一定能识别是哪一个程序拦截。

## 保存失败、设置未生效或最近结果不见了

主题和语言立即保存，服务及高级配置需要点击“保存配置”。发生冲突时重载已保存配置，再应用需要的修改；提示“已保存但视图刷新失败”时，使用重试刷新，不必重复提交。

只显示最近一次任务，清除详情后不会继续展示。旧格式任务记录不兼容，但这不会清除已有分组、设置或密钥。若只是更新插件，不要通过卸载重装排查，以免清除本地数据。

仍有问题时，请到 [GitHub Issues](https://github.com/Miraclexc/AutoTabGroups/issues) 提供浏览器与插件版本、操作入口、所选协议和脱敏错误。不要提交真实 API Key、带凭据的 URL 或私人页面内容。
