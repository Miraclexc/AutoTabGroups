## 自动浏览器冒烟测试

```bash
npx playwright install chromium --no-shell
npm run build
npm run test:browser
```

该脚本启动独立的无头 Chromium 测试配置和随机端口的本地 mock HTTP 服务，验证 React 设置、生成方案、采用方案、轻量和正文注入、实际分组、撤销及完整浏览器重启。截图保存在忽略的 `.browser-test` 中，不读取用户浏览器配置。也可提供已有 Playwright 模块目录和 Chromium 可执行文件作为两个参数。

## 扩展工具栏和其他边界的人工验收

1. `npm run check`，确认类型、lint、mock 测试和构建完成。
2. 在独立 Chrome 测试配置加载 `.output/chrome-mv3`，打开几个普通网页、一个内部页和两个窗口。
3. 点击工具栏图标，检查侧边栏能打开，分类为空时显示引导。
4. 只填名称保存分类；编辑时点击“AI 生成描述”，检查生成后可编辑、保存前不影响已有定义。导出再导入，检查 ID 保留、错误 JSON 显示错误。
5. 使用本地 mock HTTP 服务配置生成与分类地址，并分别选择 Jev、OpenAI Decisions、普通大模型。不要填写真实密钥或使用真实服务进行此验收。
6. 关闭正文，检查请求仅有标题、URL、meta 描述；开启后检查正文被提取并受长度限制。
7. 模拟高概率匹配、统一的 none（无合适分类或信息不足）、歧义概率、401、429、非法 JSON 和缺失概率键；确认候选仅含分组和 none，旧版拒绝选项响应被拒绝，旧分类缓存不会复用。
8. 同类别只有 1/2 个明确匹配标签时不创建新组；同窗口达到 3 个后批量创建。已有目标组可接收一个新标签。所有失败仍显示；固定标签和其他已有分组不动。
9. 请求期间手动导航、关闭或分组某个标签，确认不覆盖手动修改。
10. 两个窗口中的同类别标签应进入各自窗口的组，不跨窗口移动。
11. 点击撤销；被手动移动到别组的标签保持现状，其余恢复未分组。
12. 忽略一个标签，再更新，确认跳过；更改其 URL 后检查忽略不再匹配。
13. 在任务中停止 Service Worker，重新打开侧边栏或等 alarm，检查同会话恢复。
14. 重启 Chrome 并恢复上次会话，检查旧任务不使用旧 tabId、同名或已观察到的改名组自动关联。新增标签应加入原组，不出现重复组。逐个恢复其他窗口，确认延迟恢复也能关联。
15. 拒绝某网站权限或使用休眠页面，确认降级为标题和 URL，无强制唤醒。
16. 手动新建同名组，确认自动关联；新建无关组，确认仅显示在接管列表、不自动生成分类。删除绑定组后确认关联消失但分类保留，只有主动更新且同窗口达到 3 个明确匹配标签时才创建新组。
17. 同一窗口创建两个同名组，确认只选一个作为新增标签的目标，不合并已有标签、不创建第三个组。让一个原生组名称与多个分类关联，重启后应提示手动接管。

执行过哪些步骤，应在交付说明中明确；未执行的真实浏览器行为不作通过声明。
