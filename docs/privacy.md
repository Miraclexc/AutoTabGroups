# 数据与权限

[文档首页](README.md) · [使用指南](user-guide.md)

## 开发者与第三方服务

AutoTabGroups 开发者不收集或接收用户的网页信息、API Key 或使用记录。插件不向开发者服务器上传这些数据，也不内置遥测、使用统计或广告追踪。为提供用户主动请求的功能，插件会在本机读取、处理和保存必要信息，并直接向用户配置的模型或读取服务发送请求；具体数据范围见下文。

**标签归组依赖用户选择的大模型服务，我们无法保证该提供商不会收集、记录或留存请求中的信息。** 提供商是否将数据用于模型训练或其他用途、保存多久以及如何删除，取决于其隐私政策、服务条款和用户账号设置，开发者无法控制或作出保证。自定义代理、网关及远程正文读取服务也适用这一提醒。

使用前请了解所选服务的数据处理政策和可用的隐私设置，避免将不宜向第三方披露的敏感网页信息用于整理。关闭正文读取只会减少发送内容，标题、清理后的 URL 和网页描述仍会发送给模型服务。密钥保存在本机，并在请求时用于对应服务的身份验证，不发送给开发者。

## 发送给模型的信息

只有用户触发整理、说明更新或连接测试时调用模型。默认发送待处理页面标题、清理后的 URL 与页面描述；开启正文后发送受限正文。分类还包含当前窗口目标组的名称和描述。

已有组缺少说明时，标准 Chat 会接收组名与最多 5 个组内参考网页的信息。它不对这些成员重新分类。已保存描述不会因为组内导航或新成员而自动重写。

Chat 与归组模型连接测试仅发送虚构数据；读取接口测试见下文。模型请求发往用户配置的服务；没有默认云同步。URL 清理不能保证移除所有敏感信息。

## 本地存储

- 配置、密钥、分组说明和最近任务保存在本机扩展存储。
- 密钥存储不等于加密保险库；内容脚本不可读取。
- 任务只存有限摘录、标题、URL、判断分数与操作日志，不保存完整正文或密钥。
- 最近撤销独立于最近任务。清除任务详情不会删除有效撤销。
- 分类缓存仅在当前浏览器会话，最多 300 条，不按固定一小时过期；不含完整正文。
- 导出配置与说明不包含密钥、原生组／标签 ID、完整正文。导入不会操作浏览器标签。
- 旧配置可迁移。旧格式任务不读取、展示或恢复；升级前留下的旧存储键不会自动删除。新任务按当前格式记录。

## 权限

| 权限 | 用途 |
| --- | --- |
| tabs / tabGroups | 读取当前窗口标签和原生组，执行归组及明确手动操作 |
| scripting 与 HTTP(S) 主机访问 | 按用户请求提取页面信息；默认不读取正文 |
| storage | 配置、说明、任务和会话缓存 |
| sidePanel | 用户打开的操作侧栏 |
| contextMenus | 网页及扩展图标右键的三个整理动作 |
| alarms | 同会话中断任务恢复，不用于自动持续分类 |

不新增系统通知权限，不注入网页通知弹窗。快捷键任务不自动抢占其他扩展的侧栏。无痕、固定和内部页不参与自动分类。

浏览器本地正文提取排除表单和可编辑区域；远程正文由所选服务生成。输入始终是不可信资料，模型返回不能改变新建权限。日志不打印密钥、请求正文、网页正文或原始服务端错误响应。

## 可选远程正文读取

基本描述模式不会调用远程读取器。用户选择正文和 Tavily Extract／DeepSeek Fetch 后，仅向配置的读取接口提交清理后的页面 URL，使用该读取服务独立密钥，不发送浏览器 Cookie、表单输入或本地正文。服务端返回内容可能与登录态页面不同。受字符上限约束的正文随后发送给归组模型；缺失说明的组也按同一选择读取参考页。

远程失败且允许本地兜底时，改用已加载页面正文，再退回基本描述；取消不会继续兜底。读取测试使用公开 example.com，属于真实服务请求，可能产生费用。读取凭据只存于本机 credentials.v1，不返回给 UI、不写入任务、不导出，错误诊断不显示服务原始响应。读取接口遵循现有 HTTP(S) 权限，没有新增权限。
