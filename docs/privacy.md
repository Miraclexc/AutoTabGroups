# 数据与权限

[返回 README](../README.md)

## 什么会发送给模型

点击“更新分组”或“AI 生成分类”时，扩展会把参与处理的网页信息发送到你配置的模型服务：默认包括标题、清理后的网址和网页描述，开启正文读取后还包括提取并裁剪的主要文本。分类判断也会发送分类名称、描述和边界。

“AI 生成描述”仅发送分类名；“保存并测试连接”发送虚构样例。模型服务的计费与数据处理方式由对应提供方决定。

网址清理会移除常见追踪和凭据参数，但不保证移除所有敏感信息。关闭正文读取可以减少发送的内容；也可忽略不希望参与整理的标签。

## 本地保存什么

| 数据 | 保存方式 |
| --- | --- |
| 设置、分类及 API Key | 本机扩展存储；插件不云同步，分类导出不包含密钥 |
| 最近一次任务 | 标题、网址、状态、候选分数、最多 160 字的摘录和撤销信息 |
| 分组名称关联提示 | 本地保存，用于浏览器重启后重新关联已打开的组 |
| 分类判定缓存 | 当前浏览器会话内保存一小时，最多 300 条；不含完整正文 |
| 忽略列表、当前分组 ID 关联 | 当前浏览器会话内保存，重启后重建或清除 |

API Key 存储没有加密；本机扩展存储不是密码保险库。完整正文不持久化。卸载扩展会移除它的本地数据，重新加载或升级不等于清除数据。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| `tabs` | 读取标签标题、网址、窗口及分组状态 |
| `tabGroups` | 创建、查询和更新 Chrome 原生标签组 |
| `scripting` 和 HTTP(S) 网站访问 | 在用户启动任务后按需提取网页描述或正文 |
| `sidePanel` | 显示扩展侧边栏 |
| `storage` | 保存设置、分类和任务记录 |
| `alarms` | 检查并恢复当前会话中被后台休眠打断的任务，不用于持续自动分类 |

扩展跳过无痕、固定、已分组和明确忽略的标签。Chrome 限制访问的页面仍可能无法提取内容，获得网站权限并不代表能读取所有页面。

## 开发实现边界

模型请求在后台发出；凭据存储只允许可信扩展上下文访问，不提供给网页或提取脚本。提取脚本在 DOM 副本上处理文本，排除表单输入和可编辑区域。网页字段作为不可信数据传给模型。

请求拒绝重定向，日志不输出请求正文、密钥、网页正文或服务端错误响应体。实现细节见[架构说明](architecture.md)。
