# 开发过程简记

本目录仅保留开发过程的简短摘要，不保留过期计划、探索稿、截图、逐轮验收日志或发布草案。正式说明见[文档首页](../README.md)。

## 主要工作

- **归组流程**：统一当前页、窗口更新与允许新建三种动作；加入原生组关联、用户操作保护、取消、恢复和独立撤销。
- **模型与读取**：接入普通 Chat、Jev 和 Decisions 分类，补充思考参数适配、平台预设及本地／远程正文读取。
- **界面整理**：侧栏负责整理与分组管理，配置页集中服务设置和最近结果；完善窄屏、键盘操作、草稿保存与错误反馈。
- **进度与语言**：保留单条进度条并增加逐页状态；集中中英文词条，使用结构化任务消息，AI 指令统一英文，生成内容跟随所选语言。
- **文档整理**：用户指南、项目架构和开发参考独立维护；移除旧任务兼容代码与过时过程材料。

## 验证方式

开发期间使用 mock 检查模型请求与业务流程，并在隔离 Chromium 中检查原生分组和界面交互。未用这些结果代替真实服务的语义质量、账号权限或用户桌面快捷键验证。可重复执行的方法见[测试指南](../testing.md)。

后续只补充有意义的过程要点；稳定设计写入正式文档，完成的临时计划和探索材料及时清理。
